# GitHub Özellikleri

GitHub, yalnızca Git repository'lerinin saklandığı bir platform değildir. Yazılım geliştirme süreçlerini kolaylaştırmak, ekip çalışmalarını yönetmek ve proje yaşam döngüsünü desteklemek için birçok farklı özellik sunar.

Bu özellikler sayesinde geliştiriciler kod yönetiminin yanında görev takibi, dokümantasyon, otomasyon, güvenlik ve proje planlama işlemlerini de GitHub üzerinden gerçekleştirebilir.

***

### Issues

GitHub Issues, projelerdeki görevleri, hataları ve geliştirme önerilerini takip etmek için kullanılan bir özelliktir.

Issues sayesinde ekipler:

* Hata kayıtları oluşturabilir.
* Yeni özellik önerileri ekleyebilir.
* Görev dağılımı yapabilir.
* Yapılacak işleri takip edebilir.

Her issue içerisine açıklama, etiket (label), sorumlu kişi (assignee) ve kilometre taşı (milestone) bilgileri eklenebilir.

***

### Projects

GitHub Projects, proje ve görev yönetimi için kullanılan bir araçtır.

Kanban mantığıyla çalışarak görevlerin durumlarının takip edilmesini sağlar.

Örneğin:

```
To Do
  |
  ▼
In Progress
  |
  ▼
Done
```

Projects kullanılarak:

* Geliştirme süreçleri planlanabilir.
* Görevler ekip üyelerine atanabilir.
* İş akışları görsel olarak takip edilebilir.

***

### Discussions

GitHub Discussions, proje hakkında topluluk veya ekip içerisinde iletişim kurmak için kullanılan bir özelliktir.

Issues'dan farklı olarak hata takibi yerine:

* Soru-cevap
* Fikir paylaşımı
* Genel tartışmalar
* Duyurular

için kullanılır.

Özellikle açık kaynak projelerde geliştiriciler ve kullanıcılar arasında iletişim sağlar.

***

### Wiki

GitHub Wiki, repository hakkında ayrıntılı dokümantasyon oluşturmak için kullanılır.

Wiki içerisinde:

* Kurulum rehberleri
* Kullanım açıklamaları
* Teknik dokümanlar
* Proje bilgileri

yer alabilir.

***

### Releases

GitHub Releases, projenin belirli sürümlerinin yayınlanmasını sağlar.

Bir release içerisinde:

* Sürüm numarası
* Değişiklik açıklamaları
* Yayın notları (Release Notes)
* Dosya paketleri

bulunabilir.

Örneğin:

```
v1.0.0
v1.1.0
v2.0.0
```

şeklinde sürüm yönetimi yapılabilir.

***

### Gist

GitHub Gist, küçük kod parçalarını, komutları veya metin içeriklerini paylaşmak için kullanılan bir özelliktir.

Gist kullanımı:

* Kod örnekleri paylaşmak
* Kısa betikler saklamak
* Notlar oluşturmak

için tercih edilir.

***

### GitHub Marketplace

GitHub Marketplace, GitHub ile entegre çalışabilen uygulama ve araçların bulunduğu platformdur.

Burada:

* CI/CD araçları
* Kod analiz araçları
* Proje yönetim araçları
* Güvenlik araçları

bulunabilir.

***

### GitHub Codespaces

GitHub Codespaces, bulut tabanlı geliştirme ortamı sağlayan bir özelliktir.

Geliştiriciler:

* Tarayıcı üzerinden kod yazabilir.
* Hazır geliştirme ortamları kullanabilir.
* Yerel kurulum yapmadan projeleri çalıştırabilir.

Bu özellik özellikle uzaktan çalışan ekiplerde geliştirme süreçlerini kolaylaştırır.

***

### Dependabot

Dependabot, projelerde kullanılan bağımlılıkları takip eden ve güvenlik açıklarına karşı uyarılar oluşturan GitHub aracıdır.

Sağladığı özellikler:

* Güncel olmayan paketleri tespit etme
* Güvenlik açıklarını bildirme
* Otomatik güncelleme Pull Request'leri oluşturma

***

### GitHub Actions

GitHub Actions, yazılım geliştirme süreçlerinin otomatikleştirilmesini sağlayan GitHub'ın CI/CD platformudur.

Kullanım alanları:

* Otomatik test çalıştırma
* Kod derleme
* Uygulama dağıtımı
* Otomasyon işlemleri

GitHub Actions ayrı bir başlık altında detaylı olarak incelenecektir.
