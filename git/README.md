# Git

Git, yazılım geliştirme süreçlerinde kullanılan dağıtık bir versiyon kontrol sistemidir. Geliştiricilerin proje dosyalarında yaptıkları değişiklikleri takip etmelerini, geçmiş sürümlere erişebilmelerini ve farklı geliştirme süreçlerini güvenli bir şekilde yönetmelerini sağlar.

Git sayesinde geliştiriciler projelerini yerel ortamlarında yönetebilir, yapılan değişiklikleri kayıt altına alabilir ve GitHub, GitLab veya GitBucket gibi uzak repository platformları üzerinden ekip çalışması gerçekleştirebilir. Branch yapısı, commit geçmişi ve uzak depo yönetimi gibi özellikler sayesinde yazılım geliştirme süreçleri daha düzenli ve kontrollü hâle gelir.

Bu bölümde Git'in temel çalışma mantığı, mimarisi, geliştirme iş akışları, temel Git komutları, branch yönetimi, takım çalışması süreçleri ve projelerde kullanılan yapılandırma dosyaları ayrıntılı olarak ele alınacaktır. Git'in hem bireysel geliştiriciler hem de ekipler tarafından nasıl etkin şekilde kullanıldığı açıklanacaktır.
