# Git Workflow

Git Workflow, bir projede yapılan değişikliklerin Git tarafından hangi aşamalardan geçirilerek yönetildiğini ifade eden çalışma sürecidir. Yazılım geliştirme sırasında oluşturulan, düzenlenen veya silinen dosyalar belirli adımlardan geçerek sürüm geçmişine eklenir ve gerektiğinde uzak depolara aktarılır.

Git'in aşamalı çalışma yapısı, geliştiricilere yapılan değişiklikleri kontrol etme, yalnızca istenen dosyaları sürüm geçmişine ekleme ve oluşturulan sürümleri güvenli bir şekilde yönetme imkânı sağlar. Bu yaklaşım, hem bireysel projelerde hem de ekip çalışmalarında düzenli ve izlenebilir bir geliştirme süreci oluşturur.

Bir Git workflow'u genel olarak çalışma dizininde (Working Directory) yapılan değişikliklerin hazırlık alanına (Staging Area) eklenmesi, commit oluşturularak yerel depoya (Local Repository) kaydedilmesi ve ihtiyaç duyulduğunda uzak depoya (Remote Repository) gönderilmesi adımlarından oluşur.

Bu bölümde öncelikle Git'in çalışma akışı ayrıntılı olarak incelenecek, ardından gerçek bir geliştirme senaryosu üzerinden Git kullanım süreci adım adım ele alınacaktır. Böylece Git'in günlük yazılım geliştirme süreçlerinde nasıl kullanıldığı uygulamalı olarak açıklanacaktır.
