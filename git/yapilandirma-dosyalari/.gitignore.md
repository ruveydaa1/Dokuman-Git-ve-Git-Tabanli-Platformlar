# .gitignore

`.gitignore`, Git tarafından takip edilmesi istenmeyen dosya ve klasörleri belirtmek için kullanılan yapılandırma dosyasıdır. Bu dosya sayesinde geçici dosyalar, derleme çıktıları, bağımlılık klasörleri, yapılandırma dosyaları ve hassas bilgiler içeren dosyalar repository'ye eklenmeden hariç tutulabilir.

Bir projenin kök dizininde bulunan `.gitignore` dosyası, Git'in hangi dosyaları yok sayacağını belirler. Böylece gereksiz dosyaların sürüm geçmişine eklenmesi önlenir ve repository daha düzenli bir yapıya sahip olur.

### .gitignore Dosyasının Kullanım Amaçları

* Geçici dosyaların repository'ye eklenmesini önlemek.
* İşletim sistemine ait dosyaları hariç tutmak.
* Derleme ve çıktı dosyalarını sürüm kontrolüne dahil etmemek.
* Bağımlılık klasörlerini (örneğin `node_modules`) takip etmemek.
* Ortama özel yapılandırma dosyalarını ve gizli bilgileri korumak.
* Repository'nin gereksiz dosyalarla büyümesini engellemek.

### Örnek .gitignore Dosyası

```
# Bağımlılık klasörü
node_modules/

# Log dosyaları
*.log

# Ortam değişkenleri
.env

# Derleme çıktıları
dist/
build/

# İşletim sistemi dosyaları
.DS_Store
Thumbs.db
```

### Dikkat Edilmesi Gerekenler

* `.gitignore` yalnızca Git tarafından henüz takip edilmeyen dosyalar için geçerlidir.
* Daha önce repository'ye eklenmiş bir dosya `.gitignore` dosyasına eklense bile Git bu dosyayı takip etmeye devam eder.
* Hassas bilgiler (API anahtarları, parolalar vb.) içeren dosyalar mümkün olduğunca repository'ye eklenmeden önce `.gitignore` dosyasına dahil edilmelidir.

`.gitignore` dosyasının doğru kullanılması, repository'nin daha düzenli, güvenli ve yönetilebilir olmasını sağlar.
