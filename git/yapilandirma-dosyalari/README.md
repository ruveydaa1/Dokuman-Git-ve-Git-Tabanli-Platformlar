# Yapılandırma Dosyaları

Git ile yönetilen projelerde yalnızca kaynak kodları değil, projenin düzenli ve sürdürülebilir bir şekilde yönetilmesini sağlayan çeşitli dosyalar da bulunmaktadır. Bu dosyalar; hangi dosyaların versiyon kontrolüne dahil edileceğini belirlemek, proje hakkında bilgi vermek ve geliştiriciler arasında ortak bir çalışma düzeni oluşturmak amacıyla kullanılır.

Yapılandırma dosyaları, proje yönetimini kolaylaştırmanın yanı sıra gereksiz dosyaların repository'ye eklenmesini önler, proje dokümantasyonunu güçlendirir ve ekip üyelerinin proje hakkında hızlı bir şekilde bilgi edinmesini sağlar.

Bu bölümde Git projelerinde yaygın olarak kullanılan **`.gitignore`** ve **`README.md`** dosyaları incelenecek, bu dosyaların kullanım amaçları ve temel özellikleri açıklanacaktır.
